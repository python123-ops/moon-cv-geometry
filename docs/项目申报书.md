## 一、项目背景与目标

MoonBit 生态正在快速补齐基础库、工具链和应用样例，但计算机视觉方向仍缺少一个专注“几何层”的公共底座。现有图像处理或通用线性代数项目往往覆盖滤波、矩阵运算、GIS 或游戏几何，难以直接服务相机标定、AR、SLAM 入门实验、全景拼接和机器人定位等上层项目。moon-cv-geometry 的目标是提供一套边界清晰、可测试、可扩展的 MoonBit 视觉几何基础库：不做图像读取、滤波、特征提取和深度学习，而把能力集中在 2D/3D 点向量、相机模型、多视图约束和鲁棒估计上。

## 二、核心功能与创新点

项目首版提供 `core`、`camera`、`multiview`、`ransac` 四个公开包面。`core` 包含 `Point2/Point3/Vec2/Vec3/Ray3/Rect2/Mat3/Mat34`、固定尺寸矩阵运算、误差度量和几何错误类型；`camera` 提供图像尺寸、针孔内参、外参、Brown-Conrady 径向/切向畸变、投影、反投影方向、视场角和内参缩放；`multiview` 提供单应矩阵、基础矩阵、本质矩阵、极线残差、Sampson 误差和双射线三角化；`ransac` 提供带固定随机种子的单应/基础矩阵 RANSAC 估计，输出内点掩码、分数和可复现实验结果。项目采用小型固定尺寸数值工具，避免与成熟通用线代库重复，同时为视觉几何保留清晰 API。

## 三、生态差异与来源说明

选题前已查阅 mooncakes.io 相关项目。邻近项目主要集中在通用线性代数、计算/GIS 几何、渲染/游戏几何或基础图像处理，例如 `Luna-Flow/linear-algebra`、`xunyoyo/linalg`、`nummoon`、`moongeokit`、`MoonVision` 等。moon-cv-geometry 避免重复这些方向，将范围收敛到相机模型、多视图约束、几何误差与鲁棒估计。代码为原创 MoonBit 实现，仅参考公开投影几何公式和通用计算机视觉知识，不复制第三方源码，许可证采用 Apache-2.0。

## 四、开发计划与验收方式

当前版本已补齐 README、完整 Apache-2.0 LICENSE、NOTICE、CHANGELOG、CONTRIBUTING、原创性与作者身份说明、算法说明、RANSAC 参数说明、示例程序、测试和 GitHub Actions CI；GitHub 与 GitLink 默认分支均为 `main`，两端有效提交次数均保持 10 次以上，贡献者身份分别使用仓库账号本人。验证命令包括 `moon fmt --check`、`moon check --target all --deny-warn`、`moon test --target all --deny-warn`、`moon info` 和 `moon package`。后续将扩展归一化 DLT、八点法基础矩阵估计、cheirality 检查、PnP、三角化质量度量和面向 bundle adjustment 的残差接口，使其逐步成为 MoonBit 视觉几何生态的稳定基础组件。
