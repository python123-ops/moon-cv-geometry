# Contributing

This repository is prepared for OSC2026 as a single-author competition entry.
Before the competition review is complete, public contributions should be opened
as issues or design discussions rather than direct code contributions.

Quality expectations:

- Keep APIs focused on camera and multi-view geometry.
- Add tests with every behavior change.
- Run `moon check --target all`, `moon test --target all`, `moon fmt`, and
  `moon info` before proposing changes.
- Document any external algorithm reference and do not copy incompatible code.
